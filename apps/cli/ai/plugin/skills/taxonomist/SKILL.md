# Taxonomist

AI-powered WordPress category taxonomy optimizer.

Follow the full procedure documented in the `taxonomist` skill installed at `.agents/skills/taxonomist/SKILL.md` in the target site. Read that file first, then execute each step in order.

If the target site does not have the taxonomist skill installed, check if it's available at another site's `.agents/skills/taxonomist/SKILL.md` or inform the user that AI instructions need to be enabled for the site via Studio's settings.
