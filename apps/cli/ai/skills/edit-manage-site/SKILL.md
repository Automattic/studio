# Edit and Manage a Site

Use this skill for work on an existing local Studio site. A new site, a redesign, or a rebuild uses the `build-site` skill instead.

## 1. Settle the site

Start the site with site_start if it is not running.

## 2. Make the change

Load the other skills the change calls for. Follow the site's existing look — the active theme's theme.json presets and styles — rather than redesigning it; a change to the look is a change to theme.json.

## 3. Check and report

Take one screenshot of what you changed, fix real defects, then tell the user what changed and where to see it. preview_create shares a temporary preview; site_push publishes to WordPress.com.
