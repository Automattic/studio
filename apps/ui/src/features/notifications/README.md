# Notice copy

Use a short title that names the outcome or state (for example, “Site is busy”). Omit trailing periods from titles. Put explanations, recovery steps, and diagnostics in the description, using normal sentence punctuation. Titles stay on one line; disclosure makes truncated content available in full.

History cards share one trailing slot: the timestamp at rest and the action on hover or keyboard focus. Touch devices show the action. Pending actions remain visible and disabled.
