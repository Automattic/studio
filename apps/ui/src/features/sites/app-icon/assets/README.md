# App icons

Bundled PNGs keep the Open in menu and the agent apps in Settings offline and
identical in the desktop and local browser renderers. These are static brand
assets, not icons discovered from the user's installed applications. Missing
assets and image load errors fall back to the original symbol.

Visual Studio Code, Ghostty, Warp, Finder, and Terminal were exported
from their macOS application bundle icons on October 6, 2026, using `sips` at
64 pixels. Brand artwork belongs to its respective owner.

Claude, ChatGPT, and Cursor were exported from their macOS application bundle
icons on November 3, 2026, using `sips` at 256 pixels, for Settings' 32-pixel
agent app logos. Claude Code uses the Claude icon, and Codex the ChatGPT one.

Grok Build uses the Grok logo from
[SVGL](https://github.com/pheralb/svgl/blob/main/static/library/grok-dark.svg),
downloaded on November 3, 2026, as white on a dark tile with the margin of the
macOS app icons, kept as an SVG.

The phpMyAdmin icon was converted from the project's
[favicon](https://github.com/phpmyadmin/phpmyadmin/blob/master/public/favicon.ico).

Browser logos for Brave, Chrome, Chromium, Edge, Firefox, and Safari come from
[browser-logos](https://github.com/alrra/browser-logos), using its 64-pixel PNGs.
The Arc logo comes from [SVGL](https://github.com/pheralb/svgl/blob/main/static/library/arc.svg)
and was converted to a 64-pixel PNG with `sips`.

Finder and the macOS Terminal artwork are only shown on macOS. System default
browsers and apps without bundled artwork retain their existing symbols.

Opera, Vivaldi, and Firefox Developer Edition use the artwork from
[browser-logos](https://github.com/alrra/browser-logos). Zen uses its official
[site icon](https://zen-browser.app/favicon.svg), and DuckDuckGo uses its
[official logo](https://duckduckgo.com/assets/logo_header.v109.svg).
The SVGs were converted to 64-pixel PNGs with `sips`. Dia was exported from its
macOS application bundle icon on November 1, 2026, at 64 pixels.
