# Canvas Surface

The canvas should be a site-scoped surface inside Studio 2.0, not a parallel app shell.

Pull forward only the parts of the former Desks exploration that add a distinct spatial value, split
into focused site tabs:

- Site Map: pages, posts, and related content.
- Theme: visual references to a site's design system, theme materials, patterns, templates, and
  elements.

Avoid duplicating surfaces that Studio 2.0 already owns:

- Conversations and session management.
- Site creation and import.
- Site settings.
- Global settings, accounts, and app chrome.

The old `ui-desks` tree is temporarily kept as source inventory while those canvas pieces are extracted.
