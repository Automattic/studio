Curates wp-admin for the people who run a site.

== Description ==

Client Admin decides which menu items and dashboard widgets stay in wp-admin, for a Staff role or for everyone. It also registers a site's post types, taxonomies and settings pages. A second, per-site plugin holds the manifest that describes them. WordPress Studio writes that plugin.

Everything is built on WordPress: the admin menu, a custom role, post types and taxonomies, block templates, Block Bindings, the Settings API and dashboard widgets. Deactivating either plugin returns everyone to the regular admin.
